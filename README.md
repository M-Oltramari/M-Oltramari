## 👩‍💻 Sobre

Desenvolvedora web focada em criar experiências de ponta a ponta para grandes instituições, unindo boas práticas de código com design centrado no usuário.  
Gosto de trabalhar com stacks modernas (React, Next.js, Node.js) e escrever interfaces acessíveis, performáticas e intuitivas.
